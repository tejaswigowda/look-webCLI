# Bundled base VRMs

`VRoid_V110_Male_v1.1.3.vrm` and `VRoid_V110_Female_v1.1.3.vrm` are the free base models from
[hinzka/52blendshapes-for-VRoid-face](https://github.com/hinzka/52blendshapes-for-VRoid-face): VRoid models
carrying the 52 ARKit blendshapes alongside the VRM presets. The repository states they may be used freely,
personal or commercial, and redistributed or sold, with no credit or permission required. They are included
unmodified so the base selector (and `?vrm=male` / `?vrm=female`) works with no extra download.

The editor never modifies these files: exporting writes a new `*.look.vrm`.
