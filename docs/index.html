Privacy and limits
Zero egress. Your VRM and the edited file never leave this device. Open DevTools, Network tab, load a VRM and download: only static files from this site are requested, all GET, none carrying a body, cookie or credential. The one exception is a URL you name yourself, which is fetched with a read-only GET (nothing is sent). This is a pure transform: no account, token, upload or versioning. Inputs given as ?vrm= are fetched the same way, and run=export bakes without a click.
  • The editor re-exports the VRM through its own writer: the file is the editor's output, not a byte-for-byte edit of the input.
  • The editor is a patched build of the third-party cecil-tools/VRMEditorTools (MIT) with every network feature removed.
  • No service worker: it works offline after the first load because everything is a same-origin static file.
