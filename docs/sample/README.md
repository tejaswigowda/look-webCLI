# Bundled sample VRM

`VRoid_V110_Male_v1.1.3.vrm` is a free base model from
[hinzka/52blendshapes-for-VRoid-face](https://github.com/hinzka/52blendshapes-for-VRoid-face): a VRoid model
carrying the 52 ARKit blendshapes alongside the VRM presets. The repository states it may be used freely,
personal or commercial, and redistributed or sold, with no credit or permission required. It is included
unmodified so **Try with the sample** works with no extra download.

The editor never modifies this file: exporting writes a new `*.look.vrm`.
